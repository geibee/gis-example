# 地図データ操作サンプル

東京都の地理情報と不動産業務のサンプルデータを、地図と一覧で確認できるローカル実行用アプリケーションです。

## 使い方

### 起動する

Docker と Docker Compose が必要です。

初回だけ環境設定ファイルを作成します。

```bash
cp infra/.env.example infra/.env
```

アプリケーションを起動します。

```bash
docker compose -f infra/docker-compose.yml up -d --build
```

初回起動ではデータベースの作成とサンプルデータの登録を行うため、数分かかることがあります。

起動後、ブラウザーで http://localhost:5173 を開きます。

### ログインする

通常の操作確認には、編集用ユーザーを使用します。

- 編集用: ユーザー名 `gis-editor`、パスワード `gis-editor`
- 閲覧用: ユーザー名 `gis-viewer`、パスワード `gis-viewer`
- 管理用: ユーザー名 `gis-admin`、パスワード `gis-admin`

### 画面を操作する

- 「区域」「土地」「建物」「関係者」タブで、サンプルデータの一覧と詳細を確認できます。
- 右側の地図でレイヤの表示を切り替え、地物をクリックすると属性を確認できます。
- ヘッダーのアイコンで業務画面または地図を隠し、片側を広く表示できます。
- 業務画面と地図の境界をドラッグすると、地図の幅を変更できます。
- 地図ヘッダーの全画面ボタンを押すと、地図を画面全体に表示できます。`Esc` キーで元に戻せます。
- 「区域」画面では、属性や位置関係を条件に検索できます。
- 「区域」画面の新規作成から地理情報ファイルを取り込み、区域データを作成できます。

取り込みを試す場合は、次の GeoJSON ファイルを使用できます。

- `samples/geojson/parcels.geojson`: 東京駅付近を想定した土地ポリゴン2件
- `samples/geojson/buildings.geojson`: 東京駅付近を想定した建物ポリゴン2件

どちらも座標系は緯度・経度の EPSG:4326 です。

### 停止する

```bash
docker compose -f infra/docker-compose.yml down
```

データベースを削除して初期状態からやり直す場合は、ボリュームも削除してから再度起動します。

```bash
docker compose -f infra/docker-compose.yml down -v
docker compose -f infra/docker-compose.yml up -d --build
```

`down -v` を実行すると、ローカルで追加・編集したデータも削除されます。

## 使用しているデータ

初回起動時に、次の地図レイヤが登録されます。

- 地価公示 2023 東京
  - 東京都の地価公示地点
  - 出典: 国土交通省「国土数値情報 地価公示データ（2023年）」
- 小地域（町丁・字等）2020 東京
  - 東京都の町丁・字等の境界
  - 出典: e-Stat「2020年国勢調査 小地域境界」
- 坪単価200万以上の小地域
  - 地価公示と小地域を使った検索結果
  - 上記2レイヤから作成
- 商業地域・近隣商業地域 東京
  - 東京都の商業系用途地域
  - 出典: 国土交通省「国土数値情報 用途地域データ（2019年）」

画面操作を確認しやすくするため、丸の内・銀座・新橋・虎ノ門周辺を想定した次のデモレイヤも登録されます。

- 登記所備付地図 土地筆（都心サンプル）
- PLATEAU 建物（都心サンプル）
- 都心業務区域v1

これら3レイヤは実在データをそのまま収録したものではなく、業務操作の確認用に生成・加工したデモデータです。

地図に関連付ける業務データとして、次のサンプルも登録されます。

- 土地: 基本データ3件、都心デモデータ36件
- 建物: 基本データ2件、都心デモデータ36件
- 区域: 基本データ2件、都心デモデータ4件
- 関係者: 所有者、管理会社、売買事業者など
- 土地・建物・区域・関係者の関連情報

同梱している地図データは PostGIS 用の SQL に変換済みです。元の配布ファイルはリポジトリに含まれていません。
